# LinGo

LinGo — это сервис для организации и поиска досуга вместе. Веб-приложение, построенное на современном стеке технологий с использованием микросервисов.

## Технологический стек

| Технология      | Назначение                          |
|-----------------|-------------------------------------|
| Next.js         | Фреймворк для React для SSR и SSG   |
| TypeScript      | Строгая типизация для JavaScript    |
| Prisma          | ORM для удобной работы с PostgreSQL |
| PostgreSQL      | Реляционная база данных             |
| Node.js         | Платформа для микросервисов         |
| Docker          | Контейнеризация и управление средами|
| Tailwind CSS    | Утилитарный CSS-фреймворк           |


## Функционал

- Создание событий с последующим модерацией администратором.
- Просмотр, поиск и фильтрация мероприятий по категориям.
- Категорийный блок с переходом к событиям выбранного типа.
- Возможность выступить с собственным событием.
- Чат для участников событий после вступления.
- Админ-панель с функциями просмотра, редактирования, одобрения или отклонения событий.
- Уведомления через Telegram-бота о начале переписки (доступны после набора нужного количества участников).
